Collector pipeline

How the live data gets here

  • Add each Ollama account to app/config.py with its name, plan, and storage path. Pull credentials from .env (e.g. OLLAMA_EMAIL_1, OLLAMA_PASSWORD_1).
  • Run python -m app.collector --manual once per account. A real browser opens, you complete the Cloudflare-protected sign-in yourself, and the authenticated storage_state is saved to disk. Re-run with --manual-account <name> to refresh an expired session.
  • Start the FastAPI backend with uvicorn app.main:app. It scrapes https://ollama.com/settings for every account and exposes the snapshot at GET /usage.
  • APScheduler refreshes the in-memory cache every REFRESH_MINUTES (default: 2). Point the Backend URL field at http://127.0.0.1:8000 and click Refresh live data.
  • Scraped fields: sessionPercent, weeklyPercent, sessionReset, weeklyReset, plus per-model request counts parsed from the [data-usage-segment] elements on the settings page.
Ollama‑Orbit v1.0 — Data is stored in memory only. Refresh the page to reconnect to the orbit backend.
