Implementation notes

How to connect it later

  • Use one Playwright browser profile per Ollama account so each session stays signed in.
  • Visit the settings page for each account and extract session usage, weekly usage, reset text, and model names.
  • Write the data to a JSON file, then replace the sample array in this page or load it with a simple fetch endpoint.
  • Schedule refresh every 30 to 60 minutes if you want a lightweight monitor instead of real-time polling.
Ollama‑Orbit v1.0 — Data is stored in memory only. Refresh the page to reconnect to the orbit backend.
